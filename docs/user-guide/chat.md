# Chat Interface

Interactive conversational interface with LLM orchestration for natural language access to all VBAgent functions.

## Starting Chat

```bash
vbagent chat
```

## Features

- **Natural language commands** - No need to remember exact CLI syntax
- **Multi-turn conversations** - Context is maintained across messages
- **Tool orchestration** - LLM automatically calls appropriate vbagent functions
- **Rich formatting** - Beautiful terminal output with progress indicators
- **Conversation history** - Previous context is remembered
