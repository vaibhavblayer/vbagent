## New API

### classify_structural(image_path, subject=None) -> StructuralClassification
   - Stage 1: Structural classification only
   - Uses gpt-5-nano with fallback to gpt-5-mini
   - Returns: question_type, has_diagram, diagram_type, num_options, 
             num_subquestions, requires_calculus, key_concepts, confidence

### StructuralClassification Model
   Fields:
   - question_type: mcq_sc | mcq_mc | subjective | assertion_reason | passage | match
   - has_diagram: bool
   - diagram_type: free_body | circuit | graph | optics | geometry | none
   - num_options: int | None
   - num_subquestions: int (default 1)
   - requires_calculus: bool
   - key_concepts: list[str] (freeform hints)
   - confidence: float (0.0-1.0)
   - classified_at: str (ISO timestamp)

## Backward Compatibility

### classify(image_path, subject=None) -> ClassificationResult
   - Legacy v1 classifier (still works)

## Usage Example

```python

# Stage 1: Structural classification
result = classify_structural("question.png")

print(f"Type: {result.question_type}")
print(f"Has diagram: {result.has_diagram}")
print(f"Diagram type: {result.diagram_type}")
print(f"Confidence: {result.confidence}")

```
